
# Condensate-Gravity Paper (LaTeX Template)

Compile with MiKTeX (Windows) or TeX Live (macOS/Linux). Target class: APS `revtex4-2`.

## How to compile (Windows + MiKTeX)
1) Open `main.tex` in TeXworks/TeXstudio. 2) Select `pdfLaTeX`. 3) Compile. 4) Compile again to resolve refs.

## Structure
- `main.tex` (master)
- `sections/*.tex`
- `bib/references.bib`
- `figures/`

## Figures
Replace `figures/placeholder_figure.pdf` with your actual figures.

## Bibliography
Edit `bib/references.bib`, cite with `\cite{key}`.
